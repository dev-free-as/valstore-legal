이드봇 사용법

디스코드에서 발로란트 상점·전적·계정을 확인하는 방법을 처음부터 안내합니다.

안녕하세요, 이드봇입니다

라이엇 계정을 한 번 연결해 두면 오늘의 상점부터 야시장 · 번들 · 전적 · 랭크 · 지갑 · 보유 스킨 · 친구 목록까지 디스코드 안에서 바로 확인할 수 있어요. 원하는 시간에 상점을 자동으로 보내주는 알림도 지원합니다.

시작하기 로그인 계정 관리 명령어 전체 공개 범위 자동 알림 위시리스트 전적 보기 자주 묻는 질문 주의사항

1시작하기

  1. 봇이 있는 서버에 들어갑니다

    이드봇은 슬래시 명령어로 동작합니다. 채팅창에 / 를 입력하면 사용할 수 있는 명령이 목록으로 뜹니다.

  2. 라이엇 계정을 연결합니다

    /로그인 을 입력하고 로그인 방식을 고릅니다. 자세한 내용은 아래 로그인 항목을 참고하세요.

  3. 바로 사용합니다

    /상점 으로 오늘의 상점을 확인해 보세요. 명령에 따라 답변이 채널의 모두에게 보이는 것과 나에게만 보이는 것이 다르니, 아래 메시지 공개 범위를 꼭 확인하세요.

알파 테스트 중입니다. 현재는 운영자가 승인한 이용자만 명령을 사용할 수 있습니다. "알파 테스트 중"이라는 안내가 뜬다면 운영자에게 사용 승인을 요청해 주세요.

2로그인 방법

/로그인 을 실행하면 두 가지 방식 중 선택할 수 있습니다.

📱 휴대폰 QR (권장)

봇이 보여주는 QR 코드를 휴대폰의 Riot Mobile 앱으로 스캔한 뒤 승인하면 로그인됩니다. 비밀번호를 입력하지 않아 가장 안전합니다.

🔑 아이디 · 비밀번호

디스코드 입력창(모달)에 라이엇 아이디와 비밀번호를 입력하면, 봇이 라이엇 공식 로그인 페이지를 대신 진행합니다. 비밀번호는 저장되지 않습니다.

2차 인증(2FA)이 켜져 있다면 아래 단계가 추가됩니다.

  • 코드 방식 — 이메일이나 인증 앱으로 받은 6자리 코드를 버튼 → 입력창에 넣으면 됩니다. 코드 재전송·방식 변경 버튼도 함께 제공됩니다.
  • 휴대폰 승인(푸시) 방식 — Riot Mobile 앱에서 "승인"을 누르면 봇이 자동으로 감지해 로그인을 마칩니다.
로그인은 얼마나 유지되나요? 봇이 8시간마다 세션을 자동으로 갱신하기 때문에 보통 오랫동안 다시 로그인할 필요가 없습니다. 라이엇 쪽에서 세션이 끊기면 재로그인 안내 DM이 한 번 발송됩니다. 라이엇 비밀번호를 변경하면 연결이 즉시 끊깁니다.

3계정 관리

여러 개의 라이엇 계정을 등록할 수 있습니다. /계정 목록 에서 등록된 계정을 보고 버튼으로 관리하세요.

  • 세션 상태 — 🟢 정상 / 🔴 재로그인 필요
  • 현재 계정 전환 — 버튼으로 기본 계정을 바꿉니다. 다른 명령에서 계정 옵션을 생략하면 이 계정이 사용됩니다.
  • 계정 삭제 — /계정 삭제 또는 목록의 삭제 버튼(확인 단계 있음). 토큰·쿠키·알림 설정·위시리스트가 함께 지워집니다.
거의 모든 명령에는 계정 옵션이 있고, 입력하면 자동완성으로 등록된 계정 이름이 뜹니다. 생략하면 현재 계정으로 조회합니다.

4명령어 전체

로그인 표시가 있는 명령은 라이엇 계정 연결이 필요합니다.

🛒 상점

  • /상점오늘의 상점 스킨 4종과 가격·영상로그인
  • /야시장야시장 할인 스킨과 남은 시간로그인
  • /번들현재 판매 중인 번들, 버튼으로 구성 아이템 상세 보기로그인
  • /장식상점총기장식·스프레이·카드·타이틀·플렉스 (KC 상점)로그인

📊 전적 · 랭크

  • /전적최근 경기 · ACS · K/D · 헤드샷 · 승률, 모드별 필터로그인
  • /프로필계정 프로필과 경쟁전 정보(현재·최고·ELO)로그인
  • /라이브매치지금 플레이 중인 경기의 참가자·랭크 정보로그인

💰 재화 · 인벤토리

  • /지갑VP · RP · KC 잔액로그인
  • /포인트VP · RP · KC 잔액 (지갑과 동일)로그인
  • /내스킨보유한 스킨 목록 (버튼으로 페이지 이동)로그인
  • /vp계산목표 VP를 사려면 얼마가 필요한지 계산로그인 불필요

👥 소셜 · 편의

  • /친구라이엇 친구 목록과 접속 상태로그인
  • /위시리스트관심 스킨 등록 · 삭제 · 목록로그인
  • /알림상점 자동 알림 설정 · 목록 · 끄기로그인
  • /계정등록된 계정 목록 · 전환 · 삭제로그인
  • /로그인라이엇 계정 연결 (QR 또는 아이디·비밀번호)로그인 불필요
  • /설정봇 정보 — 버전 · 핑 · 가동 시간 · 서버 수 · 내 계정 수로그인 불필요

이 외에 운영자 전용 /오너 명령이 있으며, 일반 이용자는 사용할 수 없습니다.

👀 메시지 공개 범위

명령에 따라 답변이 채널의 모두에게 보이는 경우와 나에게만 보이는 경우가 나뉩니다.

🌐 모두에게 보입니다

/상점 · /야시장 · /장식상점 · /지갑 · /포인트
명령을 쓴 채널에 그대로 남아 다른 사람도 볼 수 있습니다.

🔒 나에게만 보입니다

/로그인 · /계정 · /번들 · /전적 · /프로필 · /라이브매치 · /내스킨 · /친구 · /위시리스트 · /알림 · /vp계산 · /설정

상점을 남에게 보이고 싶지 않다면 사람이 없는 채널이나 봇과의 DM에서 /상점·/야시장·/장식상점·/지갑을 사용하세요. 자동 알림도 대상을 DM으로 두면 나만 볼 수 있습니다.

5상점 자동 알림

매일 정해진 시각에 상점을 자동으로 받아볼 수 있습니다.

/알림 설정 시:9 분:0 대상:DM 내용:전체 상점

옵션설명기본값
시 (필수)보낼 시각 — 0~23 (한국 시간)—
분보낼 시각 — 0~590
계정알림을 받을 계정현재 계정
대상DM (개인 메시지) 또는 채널DM
채널대상이 '채널'일 때 보낼 텍스트 채널—
내용전체 상점 또는 위시리스트만전체 상점
  • /알림 목록 — 내가 설정한 알림을 모두 확인
  • /알림 끄기 — 해당 계정의 알림 중지
위시리스트만을 고르면 등록해 둔 스킨이 상점에 떴을 때만 알림이 옵니다. 하루에 한 번만 발송되며, DM으로 받으려면 서버 멤버의 DM이 차단되어 있지 않아야 합니다.

6위시리스트

  • /위시리스트 추가 스킨:프라임 밴달 — 스킨 이름은 자동완성으로 골라 주세요.
  • /위시리스트 목록 — 등록한 스킨 확인
  • /위시리스트 삭제 — 등록된 스킨 중에서 선택해 제거

위시리스트는 계정별로 저장되며, 자동 알림의 "위시리스트만" 옵션과 연동됩니다.

7전적 보기

/전적 을 실행하면 현재 랭크와 최근 경기 요약이 함께 표시됩니다.

  • 퍼포먼스 요약 — K/D · ACS · 헤드샷 처치율 · 승률
  • 플레이 분석 — 최다 플레이 요원, 최고 승률 요원 · 맵
  • 모드 선택 메뉴 — 전체 / 경쟁전 / 일반전 / 신속플레이 / 스파이크 돌격 / 데스매치 / 팀 데스매치 / 에스컬레이션 / 사용자 설정으로 바꿔 볼 수 있습니다.

전적·랭크 데이터는 외부 공개 API(HenrikDev)를 사용하기 때문에, 방금 끝난 경기는 잠시 뒤에 반영될 수 있습니다.

8자주 묻는 질문

비밀번호가 저장되나요?

아니요. 봇은 라이엇 비밀번호를 저장하지 않습니다. 아이디·비밀번호 로그인은 라이엇 공식 로그인 페이지에 전달하는 용도로만 쓰이며, QR 로그인은 애초에 비밀번호가 봇에 전달되지 않습니다. 자세한 내용은 개인정보 처리방침을 참고하세요.

"세션이 만료되었습니다"라고 떠요.

라이엇 세션이 끊긴 경우입니다. /로그인 으로 다시 연결하면 기존 설정(알림· 위시리스트)은 그대로 유지됩니다.

계정이 여러 개인데 매번 골라야 하나요?

/계정 목록 에서 자주 쓰는 계정을 현재 계정으로 지정해 두면 계정 옵션을 생략해도 그 계정으로 조회합니다.

알림이 오지 않아요.

① DM 차단 여부, ② /알림 목록 에서 시간·대상이 맞는지, ③ 계정 세션이 🟢 정상인지 확인해 주세요. 채널로 받는 경우 봇이 그 채널에 메시지를 보낼 권한이 있어야 합니다.

다른 사람에게 내 상점이 보이나요?

네, /상점·/야시장·/장식상점·/지갑· /포인트의 답변은 채널의 모두에게 보입니다. 반대로 /로그인·/계정·/전적·/내스킨 등은 본인에게만 보입니다. 자세한 구분은 메시지 공개 범위를 보세요. 남에게 보이지 않게 하려면 봇과의 DM이나 개인 채널에서 사용하고, 자동 알림 대상도 DM으로 설정하세요.

등록한 정보를 지우고 싶어요.

/계정 삭제 를 사용하면 토큰·쿠키·알림 설정·위시리스트가 즉시 삭제됩니다.

명령어가 목록에 안 보여요.

봇이 서버에 막 초대되었거나 업데이트 직후일 수 있습니다. 잠시 후 디스코드를 새로고침 (Ctrl + R) 해 보세요. 그래도 안 되면 알파 테스트 승인 여부를 확인해 주세요.

  • 자세한 내용은 이용약관과 개인정보 처리방침을 확인해 주세요.
