개인정보 처리방침

시행일: 2026년 7월 25일

전략가 곰(VALSTORE)(이하 "봇")은 서비스 제공에 필요한 최소한의 정보만을 수집하며, 이용자의 개인정보를 소중히 다룹니다. 본 방침은 봇이 어떤 정보를 수집하고 어떻게 이용·보관·파기하는지를 설명합니다.

1. 수집하는 정보

  • Discord 계정 식별자 — Discord 사용자 ID(등록한 계정을 연결·관리하기 위함).
  • Riot 계정 인증 정보 — 로그인 시 발급되는 액세스 토큰, 엔타이틀먼트 토큰, 세션 쿠키(ssid 등). 게임 데이터 조회 및 세션 유지에 사용됩니다.
  • Riot 계정 식별 정보 — PUUID, 지역(region), 게임 이름 및 태그(GameName#Tag).
  • 이용자 설정 — 상점 알림 설정, 위시리스트 등 이용자가 직접 등록한 정보.

봇은 Riot 계정의 비밀번호를 저장하지 않습니다. 아이디/비밀번호 로그인은 Riot 공식 로그인 창을 통해서만 처리되며, 결과로 발급된 토큰·쿠키만 저장됩니다.

2. 이용 목적

  • 상점·야시장·번들·장식상점·랭크·프로필·지갑·보유 스킨·친구 목록 등 기능 제공
  • 로그인 세션 유지(만료 방지를 위한 주기적 토큰 갱신)
  • 이용자가 설정한 자동 상점 알림 발송

3. 보관 및 보안

  • 수집한 정보는 봇 운영 서버의 로컬 데이터베이스(SQLite)에 저장됩니다.
  • 인증 토큰·쿠키는 게임 데이터 조회 및 세션 유지 목적 외에는 사용되지 않습니다.
  • 봇은 이용자의 정보를 광고 등 상업적 목적으로 이용하거나 제3자에게 판매하지 않습니다.

4. 제3자 서비스

봇은 기능 제공을 위해 다음 외부 서비스와 통신합니다.

  • Riot Games API — 상점·랭크·지갑·친구 등 게임 데이터 조회(인증 필요).
  • HenrikDev VALORANT API — 랭크·프로필·서버 상태 등 공개 전적 데이터 조회.
  • Discord — 명령 처리 및 메시지 전송.

5. 보관 기간 및 파기

  • 이용자가 /계정 삭제 명령을 사용하면 해당 계정의 토큰·쿠키·설정 등 관련 데이터가 즉시 삭제됩니다.
  • 서비스 종료 시 보관 중인 모든 이용자 데이터는 파기됩니다.

6. 이용자의 권리

이용자는 언제든지 자신의 등록 계정을 조회(/계정 목록)하거나 삭제(/계정 삭제)할 수 있습니다. 또한 Riot 계정의 비밀번호를 변경하면 저장된 세션이 무효화됩니다.

7. 아동의 개인정보

봇은 Discord 및 Riot Games의 최소 이용 연령 정책을 따릅니다. 해당 연령 미만의 이용자로부터 정보를 수집하지 않습니다.

8. 방침의 변경

본 방침은 필요 시 개정될 수 있으며, 변경 내용은 본 페이지에 게시된 시점부터 적용됩니다.

9. 문의

개인정보 관련 문의는 봇 운영자(디스코드)를 통해 접수할 수 있습니다. ※ 배포 시 연락처(디스코드 서포트 서버 초대 링크 또는 이메일)를 기입하세요.
